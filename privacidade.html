Política de Privacidade

Atualizada em 31 de outubro de 2026. Voltar ao início

Esta política vale para o app "fabrica", a ferramenta interna do canal Abrigo Music. O app é usado somente pelo responsável pelo canal, na própria conta do canal. Ele não é oferecido a outras pessoas.

Dados acessados

Com a autorização da conta do canal, o app usa as APIs do YouTube para enviar e gerenciar vídeos, ler e gerenciar comentários e ler estatísticas do canal. Não coletamos dados de quem apenas assiste aos vídeos, além do que o YouTube mostra ao dono do canal: comentários públicos, com o nome público de quem comentou, e números agregados.

Como os dados são usados

Os dados servem só para operar o canal: publicar vídeos, responder comentários e entender o desempenho do conteúdo. Comentários e estatísticas podem ser analisados por ferramentas de inteligência artificial usadas pelo responsável pelo canal, somente para essa finalidade.

Armazenamento e compartilhamento

A autorização de acesso fica guardada em computador privado, com acesso restrito. Os dados não são vendidos, não são usados para publicidade e não são compartilhados, exceto com os provedores de ferramentas citados acima ou quando a lei exigir.

Serviços do Google e do YouTube

O app usa os Serviços de API do YouTube. Ao usá-lo, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google. O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento na página de permissões da Conta do Google.

Exclusão de dados e contato

Para pedir a remoção de um dado seu ou tirar dúvidas, escreva para deusage7@gmail.com.
